modによらない(さすがに合成数とかだと厳しいが)共通した処理を実装している。

`FPS<mint>` は係数を昇べき順に保持する形式的べき級数で、`size()` は係数の個数を返す。以下の `deg` / `sz` は次数ではなく計算する係数の個数（$x^0$ から $x^{deg-1}$ まで）を表す。`deg == -1` を受け付ける関数では、入力の `size()` を使う。

## コンストラクタ
```
FPS(vector<mint> vec)
```
係数列 `vec` から構築する。`vec[i]` が $x^i$ の係数。

```
FPS(initializer_list<mint> ilist)
```
係数列 `ilist` から構築する。例: `FPS<mint>{1, 2, 3}` は $1+2x+3x^2$。

```
FPS(int sz)
```
`sz` 個の 0 係数で初期化する。最大の次数ではなく項数を指定する。

いずれのコンストラクタも、係数数を $N$ として構築時間・空間は $O(N)$。


## diff
微分した形式的べき級数を返す。入力の係数数が $N$ のとき、出力は最大 `N-1` 項。

### 計算量
mintが四則演算 $O(1)$ なら、
- $O\left(N\right)$


## integral
積分した形式的べき級数を返す。定数項は 0 とする。係数 `i` を `i+1` で割るため、係数体で必要な逆元が存在すること。

### 計算量
mintが四則演算 $O(1)$ なら、
- $O\left(N\right)$

## inv系

`inv(deg)` と `inv_naive(deg)` は定数項が 0 でない級数の乗法逆元を `deg` 項返す。`deg == -1` なら入力サイズまで計算する。高速な畳み込みを使う場合、出力項数を $N$ として $O(N\log N)$、ナイーブな畳み込みでは $O(N^2)$。

### 計算量
計算量は使用する畳み込み実装による。出力項数を $N$ として、高速な畳み込みなら $O(N\log N)$、ナイーブな畳み込みなら $O(N^2)$。

## log
`log(f)` を `deg` 項求める。定数項 `f[0] == 1` が必要。`deg == -1` なら入力サイズまで。

### 計算量
高速な畳み込みでは $O(N\log N)$、ナイーブな畳み込みでは $O(N^2)$。

## sqrt

`deg` 項までの平方根を求める。`deg == -1` なら入力サイズまで。平方根が存在しない場合はサイズ `0` のFPSを返す。

先頭の非ゼロ項の次数が奇数の場合や、先頭係数が平方剰余でない場合は存在しない。

### 計算量

- 高速な畳み込みでは $O(N\log N)$、ナイーブな畳み込みでは $O(N^2)$。


## pow

`f^k` の先頭 `deg` 項を返す。`k` は非負整数、`deg == -1` なら入力サイズまで。実装は最低次数と最低係数を処理して計算する。計算量は高速な畳み込みなら $O(N\log N)$、ナイーブな畳み込みなら $O(N^2)$（$N=deg$）。


## 多項式の除算と余り

`%`や`/`が演算子オーバーロードにより実装されているので、それを使う。

分母の最高次係数は 0 でないこと。`/` は商、`%` は余りを返す。

### 計算量
$f$の次数を$N$,$g$の次数を$M$として $f/g$の商と余りを、
- $O((N+M)\log(N+M) + M\log M)$
で求められる。

## 疎なFPSの場合の高速化

FPSの非ゼロな項が少ない（スパースである）場合、いくつかの操作は $O(N \log N)$ よりも高速に行うことができます。
これらの操作は `fps-sparse.hpp` に実装されており、`FPS` クラスのメンバ関数として呼び出すことができます。

- `mul_sparse(g, deg)`: スパースな `g` との乗算
- `inv_sparse(deg)`: 逆元
- `exp_sparse(deg)`: 指数関数
- `log_sparse(deg)`: 対数関数
- `pow_sparse(k, deg)`: 累乗

詳細については、[fps-sparse(疎な場合の高速化)](./fps-sparse.md) のドキュメントを参照してください。
