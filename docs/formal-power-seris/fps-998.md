## 畳み込みと逆元

このページは `FPS<mint>::multiply` と `FPS<mint>::inv` の 998244353 向け実装を定義する。係数は `modint998244353` を使う。

- `multiply(a, b)`: 係数列 `a`, `b` の積を昇べき順の係数列で返す。長さを $n,m$ とし、小さい側の長さが 40 以下なら時間 $O(nm)$、それ以外は $O(L\log L)$（$L$ は $n+m$ 以上の最小の2冪）。NTT の長さは $2^{23}$ 以下。
- `inv(deg)`: 定数項が 0 でない FPS の逆元を `deg` 項まで返す。`deg == -1` の場合は元の FPS のサイズまで。計算量は $O(L\log L)$（$L=\texttt{deg}$）。
